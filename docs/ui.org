* 两形态总览

| 形态 | 入口 | 产物 | 定位 | 依赖 |
|---|---|---|---|---|
| org 报告 | =M-x el-chronos-report= / =el-chronos-weekly-report= | =*el-chronos-report*= buffer / org 文件 | 归档、版本间 diff、导出 CSV/JSON | 零第三方 |
| 浏览器 Web dashboard | =M-x el-chronos-web-start= | =http://127.0.0.1:8787/= | 深度分析：多图表、搜索排序分页、火焰图、多会话对比 | 零第三方（内置 =make-network-process=） |

共同约束：

- **只读**：两者都只查库。Web 路由表里没有任何写入 / 执行入口（I8）。
- **数据同源**：数字必然一致，不存在「两边对不上」；新增一种形态不需要改采集与存储。
- **降级可见**（I11）：端口占用 → =user-error= 且不换端口，不静默失败。任何一种失败都不影响采集与其他形态。

* 浏览器 Web dashboard（=M-x el-chronos-web-start=）

** 路由表（13 条，全部 GET、只读）

| # | 方法 | 路径 | 参数 | 返回键 |
|---|---|---|---|---|
| 1 | GET | =/= | — | 内嵌单页 HTML（=text/html=） |
| 2 | GET | =/api/summary= | =range= | =range= =generated-at= =overview={:commands :blocked-ms :slow-commands :samples :db-size :startup-ms :sessions}= |
| 3 | GET | =/api/top-functions= | =range= =limit=（默认 20） | =range= =limit= =items=[{:function :file :package :self-ms :samples :pct}]= |
| 4 | GET | =/api/slow-commands= | =range= =limit=（默认 20） | =range= =limit= =items=[{:name :count :total-ms :max-ms :avg-ms :aborted}]= |
| 5 | GET | =/api/packages= | =range= | =range= =limit=（nil，不限）= =items=[{:package :self-ms :pct}]= |
| 6 | GET | =/api/trend= | =range= =buckets=（省略则由窗口长度决定 24/168/720） | =range= =limit= =items=[{:bucket :samples :slow-commands :blocked}]= |
| 7 | GET | =/api/heatmap= | =range= =limit=（默认 20） | =range= =limit= =items=[{:bucket :command :count :duration-ms}]= |
| 8 | GET | =/api/stacks= | =range= =limit=（默认 50） | =range= =limit= =items=[{:stack :samples :pct}]= |
| 9 | GET | =/api/sessions= | =range= | =range= =limit=（nil）= =items=[{:id :started-at :startup-ms :emacs-version :host}]= |
| 10 | GET | =/api/blocking= | =range= =limit=（默认 20） | =range= =limit= =items=[{:id :ts :duration-ms :kind :command :mode :project}]= |
| 11 | GET | =/api/regressions= | =range=（被忽略） =limit=（默认 20） | =range= =limit= =items=[{:function :current-ms :previous-ms :growth :current-samples :previous-samples}]= |
| 12 | GET | =/api/event= | =id=（正整数） | 单事件对象 ={:id :ts :duration-ms :kind :command :stack :context}=；缺失/非法/不存在 → =null= |
| 13 | GET | =/api/export.csv= | =range= | 多区块 CSV（=text/csv= + =Content-Disposition: attachment=） |

约定：

- 列表接口响应恒含 =range= =limit= =items= 三键（前端无需按接口分支）；=limit= 为 =null= 表示不限。
- =range= 取 =1d= / =7d= / =30d=，非法或缺失回落 =7d=；=limit= 上限 =1000=。
- =/api/event= 用「200 + =null=」而非 404：事件可能已被保留策略清理，属正常空结果；
  只有未知路径才 404。非 GET → 405（带 =Allow: GET=），路径不以 =/= 开头 → 400，
  请求头超过 =16384= 字节 → 413。

页面结构（=el-chronos-web--markup=，无 CDN、无第三方库）：

| 慢命令 | =#q-slow= 搜索 + =table#t-slow= | 表格：列排序、分页 10 行 |
| 热点函数 | =#q-func= 搜索 + =table#t-func= | 同上 |
| 阻塞事件 | =table#t-block= | 表格 + 行点击下钻 |
| 回归 | =table#t-reg= | 表格 |

| 火焰图 | =svg#flame= + =#flame-legend= | **按层聚合近似**：栈按层级折叠，深度 ≤6 层，宽度按样本数占比 |
| 下钻侧栏 | =aside#panel=（=#panel-close= / =#panel-body=） | 行点击 → =/api/event= 或本地已取数据渲染 |

前端状态对象 =S=：=range=、=auto=、=timer=、=per=（每页 10 行）、=data=、=view=、
=sort= / =dir=（各表的排序列与方向）、=q=（搜索词）、=page=。所有数据经 =fetch= 取 JSON，
渲染在本地完成；断网无影响（同源、无外链资源）。

** 只读与 loopback 边界

- 只绑 =127.0.0.1=（=el-chronos-web--host= 是常量，不接受 =0.0.0.0=），端口 =el-chronos-web-port=（默认 8787）。
- **无鉴权**。loopback 只防 LAN 暴露，**不构成本机访问控制**：WSL2 mirrored 网络共享端口空间，
  Windows 侧进程可直接访问该端口（I8，见 [[file:../Readme.org][Readme]]「隐私边界」）。
- 默认不自动启动（=el-chronos-web-auto-start= 为 nil）；端口占用 → =user-error=，
  **不自动换端口**（I11）。用完 =M-x el-chronos-web-stop= 释放端口。
- 端口 =0= 时由内核分配：=el-chronos-web-start= 的 =message= 与 =user-error= 一律取
  =(process-contact PROC :service)= 反映**实际绑定**端口（取不到才回落入参），因此传 =0= 也不会
  提示「http://127.0.0.1:0/」。调用方可用 =(process-contact (el-chronos-web-start))= 核验。
- 路由表无写入 / 执行入口；CSV 导出也是只读查询 + 格式化。

** 单线程串行处理的含义

- 请求处理在 **Emacs 主线程同步执行**：=:filter= 收字节 → 凑到 =\r\n\r\n= → 解析请求行 → 一次响应
  → =Connection: close= + EOF 关闭。因此**不需要** keep-alive、分块传输、长连接超时管理。
- 后果一：响应时间 = 查询时间（SQLite 本地读取，毫秒级）；并发请求在 Emacs 里**排队**，
  不是并行——多个标签页同时刷新会串行处理。
- 后果二：单个慢查询会占住主线程（进而让采集的 timer 延迟）。因此列表接口都有 =limit= 上限
  （默认 20、最大 1000），堆栈默认 50，包占比不分页。
- 后果三：单请求累积上限 16KB（=--max-request-bytes=），超出返回 413，防畸形请求无限占内存。
- 单请求异常 → 500 且 server 继续服务（I11：不因一次坏请求整体挂掉）。
  **500 不回显内部错误**：浏览器只看到通用文案「请求处理失败。内部错误详见 Emacs 的 =*Messages*=。」，
  错误详情（常含绝对路径与 SQL 片段）经 =display-warning= 写到 Emacs 侧 =\*Messages\*=
  / =\*Warnings\*=，本机用户仍能排障——可见降级但不向浏览器泄露实现细节。

* org 报告（=M-x el-chronos-report=）

10 节，按 =el-chronos-report--content= 的输出顺序：

| # | 节 | 数据来源 | 展示上限 |
|---|---|---|---|
| 1 | 概览 | =el-chronos-analysis-overview= → =--section-overview= | — |
| 2 | 慢命令 TOP | =el-chronos-analysis-slow-commands= | 20 行；列：命令/次数/总耗时/最大/平均/中断数 |
| 3 | 热点函数 TOP | =el-chronos-analysis-top-functions= | 20 行；列：函数/包/self/样本/占比 |
| 4 | 包归因 | =el-chronos-analysis-package-breakdown= | 不限（unknown 与 GC 恒排末尾） |
| 5 | 趋势 | =el-chronos-analysis-trend= | 最近 48 桶；列：小时/样本/慢命令/阻塞 |
| 6 | 阻塞事件 | =el-chronos-analysis-blocking-events= | 20 行；列：时间/时长/命令/mode/project |
| 7 | 回归（近 N 天） | =el-chronos-analysis-regressions= | 20 行；标题天数取 =el-chronos-regression-window-days= |
| 8 | 用法 TOP | =el-chronos-analysis-heatmap= 按命令聚合（=--usage-rows=） | 见实现 |
| 9 | 会话 | =el-chronos-analysis-sessions= | 20 行；列：开始时间/启动耗时/版本/主机 |
| 10 | 调用栈 TOP | =el-chronos-analysis-stacks= | 10 行；栈自 leaf 起最多 8 帧 |

相关入口：

- =el-chronos-report= 交互选范围（默认 =7d=），生成只读 org buffer。
- =el-chronos-weekly-report= 把近 7 天报告写入 =chronos-weekly.org=（默认落运行时状态目录）。
- =el-chronos-export= 导出 CSV（=# section:= 分块）或 JSON（单对象，含 overview 与各明细区块）。
- =el-chronos-show-event= 展示单条慢事件完整栈与 context（=*el-chronos-event*= 只读 buffer）。
- =el-chronos-profile-command= 对单条命令做 1ms 高精度剖析（不查库，实时跑一次）。

* 性能注意

| 项 | 取值 | 控制手段 |
|---|---|---|
| Web 列表分页 | 前端每页 10 行（状态对象 =per=） | 单页行数固定，避免一次把全部排行塞进 DOM |
| Web 查询 | 列表 =limit= 默认 20、上限 1000；堆栈默认 50 | 单线程串行，长查询会占主线程 |
| Web 请求上限 | 单请求累积 16384 字节（=el-chronos-web--max-request-bytes=） | 超出返回 413，防畸形请求无限占内存 |
| Web 前端 | 一次取数 + 本地渲染；自动刷新默认 30s | 关掉自动刷新即零轮询；搜索 / 排序 / 分页均在本地数据上做 |
| org 报告 | 慢命令 / 热点函数 / 阻塞 / 回归 / 会话各 20 行；趋势最近 48 桶；栈 10 行 | 报告一次成型、无增量渲染；重查询期间抑制阻塞判定，避免把报告耗时记成假阻塞 |
